プライバシーポリシー

### ホスティング
- GitHub Pages / Netlify / Vercel 等の静的ホスティングで公開
- マークダウンを HTML に変換するか、`<pre>` で囲んで公開しても可
- 公開後のURLを `settings_screen.dart` の `_kUrlPrivacy` と paywall_screen.dart の `_kUrlPrivacy` の両方に反映
- App Store Connect と Play Console の「プライバシーポリシーURL」欄にも入力（提出必須）


サブすく
- `privacy_policy.md` と同じドメイン下にぶら下げると管理が楽
- 例：`https://example.com/subscription`
- URL を `terms_of_service.md` 第6条、paywall_screen.dart、settings_screen.dart に反映
